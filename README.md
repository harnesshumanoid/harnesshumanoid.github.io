# HarnessHumanoid

Project website: https://harnesshumanoid.github.io/

Static HTML, CSS, and JavaScript. Preview with `python3 -m http.server 4187` and open http://localhost:4187.

All 42 demonstration videos come from the selected final presentation bundle. The 20 initial-position clips and 12 home replays are encoded at 5× speed; station and IK/VLA comparisons are at 1×. The hero combines 12 homes into a 4-column × 3-row montage. Each home includes an ordered task caption derived from its verification record.

The method diagrams are the overview and agentic execution loop from the project manuscript. Local font files include their SIL Open Font licenses.

GitHub Actions deploys this directory to GitHub Pages on each push to `main`.
