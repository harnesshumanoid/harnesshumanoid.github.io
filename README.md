# HarnessHumanoid

Project website: https://harnesshumanoid.github.io/

Static HTML, CSS, and JavaScript. Preview with `python3 -m http.server 4187` and open http://localhost:4187.

All 42 demonstration videos come from the selected final presentation bundle. The 20 initial-position clips and 12 home videos are encoded at 3× speed; station and IK/VLA comparisons are at 1×. The hero combines 12 homes into a 4-column × 3-row montage. Each home includes an ordered task caption derived from its verification record.

The hero opens with a cleaned 15-second real-robot clip starting at 0:01 (the burned-in task captions are inpainted out), then crossfades into the twelve-home montage. A closing Real-Robot Execution section plays the full 53-second physical run with a moving spotlight that follows the active task and dims the rest of the scene; the chapter cards jump to the door, box, and chair segments.

The first method overview from the manuscript appears before the experiment videos. Experiment headings follow the manuscript. The twelve long-horizon videos use a compact three-column layout, showing sequence numbers and ordered tasks without scene descriptions. Local font files include their SIL Open Font licenses.

GitHub Actions deploys this directory to GitHub Pages on each push to `main`.
